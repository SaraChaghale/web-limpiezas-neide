# Propuesta de Diseño - Servicio de Limpieza

Este repositorio contiene una propuesta de diseño para el sitio web de una empresa de servicios de limpieza. El enfoque principal ha sido crear una interfaz moderna, limpia y responsive utilizando HTML y CSS.

## Estado del Proyecto
